# Project instructions

## Testing policy

- Do not create or expand unit tests or regression tests unless the user explicitly
  requests them.
- Preserve existing tests; do not remove or weaken them as part of unrelated work.
- Validate changes with the applicable typecheck, lint, build, formatting, contract
  generation, and focused manual/static inspection.
- Automated unit/regression tests are not an acceptance requirement for this
  project unless the user explicitly changes this policy.
