# Fluxo API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a primeira versão executável da API Fluxo, conectada ao Neon e compatível com o contrato do FinanceMobileApp.

**Architecture:** Monólito modular NestJS/Fastify. Controllers conhecem HTTP e schemas Zod, services conhecem regras e erros de domínio, repositories são a única camada que conhece Prisma. Autenticação global injeta `userId`; persistência, auditoria, idempotência e agregações são feitas no PostgreSQL.

**Tech Stack:** Node 22, TypeScript strict, NestJS 11.1.x, Fastify, Prisma 7.9+, PostgreSQL/Neon, Zod 4, Vitest, Supertest, Pino, Swagger.

## Global Constraints

- Dinheiro é `number` inteiro em centavos e todo campo público termina em `Cents`.
- Datas públicas são ISO 8601 UTC; agregações usam `America/Sao_Paulo`.
- Nenhum `userId` é aceito em body ou query.
- Nenhum `PrismaService` é importado fora de repositories e infraestrutura de banco.
- Nenhuma regra de negócio ou `HttpException` vive em controller/service.
- Toda entidade de negócio usa soft delete.
- Insights agregam em SQL parametrizado, nunca em memória.
- Todo endpoint tem schema Zod de entrada e saída.
- TypeScript strict, sem `any`, `require`, `__dirname` ou segredos versionados.
- Migration aplicada não é editada; runtime usa URL pooled e migration usa URL direta.

```ts
export function splitInstallments(totalCents: number, count: number): number[] {
  const base = Math.floor(totalCents / count);
  const remainder = totalCents % count;
  return Array.from({ length: count }, (_, index) =>
    base + (index < remainder ? 1 : 0),
  );
}
```
